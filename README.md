# Jaysden
Jaysden is intended to be a demoscene-inspired search engine, inspired by legwork.i2p to be built on YaCy and made to honor a mutual who passed away. The idea is to apply demoscene techniques and principles to I2P's decentralization by building an advanced crawler that connects to and indexes as many eepsites across I2P as it can reach, while leaving out anything explicitly illegal or blacklisted. The crawler should go past what the I2P-based YaCy network of what legwork.i2p's "intranet indexing" setup already covers, and index more of the network than any eepsite index or search engine has managed so far. Since YaCy is already open-source, the point of Jaysden.i2p in a technical sense, if to have an improved version of legwork.i2p with a much wider database, so as to breaks I2P's vicious cycle of looking emptier than it actually is, for the purpose of making full use of how decentralized and open the network already is.
